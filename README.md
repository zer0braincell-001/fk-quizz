# fk-quizz

Quiz drill pilihan ganda — genetika molekuler hemoglobinopati & thalassemia (71 soal). Single-file `index.html`, vanilla JS, zero dependency; jalan di browser tanpa server.

Fitur: navigator per-nomor (jump/flag/preview), acak opsi + acak urutan soal, Mode Ujian (kunci disembunyikan s/d "Selesai & koreksi"), skor + progress, light-first + toggle tema, progres tersimpan di localStorage.

Sumber jawaban: PPT "Dasar Genetika Molekuler Hemoglobinopati" — dr. Danus Hermawan, Biokimia FK UNS.

## Catatan akurasi
- #12 & #13 korup (di-skip). #28 typo (β = 146 aa, tapi opsi 146 tidak ada). #11 nyasar (rabies). #20 kaitan G6PD rancu.
- 5 soal bergambar (#16, 35, 36, 59, 60) & timing gestasi (#5, 45, 55, 56): kunci mengikuti pola sumber, belum diverifikasi dari gambar/kunci dosen.
